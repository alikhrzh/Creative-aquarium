 Overview
**Creative Aquarium** is an interactive **Java Swing** project simulating an animated underwater world inspired by *SpongeBob SquarePants*.  
It brings the iconic Bikini Bottom to life — featuring animated characters, houses, and a submarine exploring the ocean.

---

 Features
-  **Gary the Snail** moving along the sand  
-  **Submarine** smoothly floating from right to left in a loop  
-  **Houses** of SpongeBob, Squidward, and Patrick  
-  GIF-based animations with custom rendering  
-  Built entirely with **Java AWT/Swing**  
-  Extensible architecture for adding keyboard/game controls  

---

##  Technical Highlights
| Component | Description |
|------------|-------------|
|  **Animation Engine** | Custom AWT double-buffered rendering loop |
|  **Movement Logic** | Controlled frame-by-frame motion system |
|  **Graphics** | Transparent PNG and GIF sprite layering |
|  **Architecture** | Object-oriented classes for each character and element |
